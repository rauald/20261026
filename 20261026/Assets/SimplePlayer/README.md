# Simple Player Demo

Unity에서 이 프로젝트를 열면 스크립트 컴파일 후 Assets/Scenes/PlayerDemo.unity 씬이 자동 생성되어 열립니다.
기존 씬에 저장하지 않은 수정이 있으면 먼저 저장 여부를 확인합니다.
자동 생성이 취소되었으면 Tools > Simple Player > Open Demo를 실행하세요.
생성된 씬에서 Play를 누르고 Game 창을 클릭하세요.

W: 바라보는 방향으로 전진 / S: 방향을 유지한 채 후진 / A: 왼쪽 회전 / D: 오른쪽 회전
A/D를 누르는 동안 초당 180도(90도에 0.5초)로 회전합니다. W/S와 동시에 사용할 수 있습니다. 후진해도 카메라 방향은 유지됩니다. 카메라 회전에도 별도 감쇠를 적용합니다.
Space: 지면에서 점프 (기본 높이 2.5, Inspector에서 최대 5)
팔과 다리가 걸을 때 앞뒤로 흔들립니다.
카메라는 LateUpdate와 SmoothDamp로 캐릭터 머리 뒤 위쪽을 따라갑니다.

캐릭터: 머리 1, 몸통 1, 팔 2, 다리 2 (렌더링 도형 총 6개).
관절용 빈 Pivot에는 렌더러가 없습니다.
바닥: Plane, Scale (4,1,4), 기본 Material 유지.
장애물: Cube 한 개, 기본 Material 유지.
캐릭터에만 단색 Material 3개를 적용합니다.
기존 SampleScene은 보존되며 생성된 PlayerDemo가 빌드의 첫 씬으로 등록됩니다.
바닥 밖으로 추락하면 시작점으로 복귀합니다.


점프 시 양팔을 들고 다리를 벌리는 공중 자세를 적용하며, 착지하면 걷기/정지 자세로 부드럽게 돌아옵니다. 이동 없이 점프해도 적용됩니다.
Play 시 몸통의 앞면(+Z)이 단색 노란색으로 표시됩니다. 기존 몸통 면의 색만 바꾸므로 캐릭터 도형은 6개로 유지됩니다.
